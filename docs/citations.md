# Data citations

Use these when you describe the recordings. The same text is stored on each prepared JSON file and shown at the bottom of the lessons.

## EEG

Schalk, G., McFarland, D.J., Hinterberger, T., Birbaumer, N., Wolpaw, J.R. BCI2000: A General-Purpose Brain-Computer Interface (BCI) System. IEEE Transactions on Biomedical Engineering 51(6):1034–1043, 2004.

Schalk, G. EEG Motor Movement/Imagery Dataset (version 1.0.0). PhysioNet. 2009. https://doi.org/10.13026/C28G6P

Runs used:

| File | What it is |
| --- | --- |
| S001R01, S002R01 | Baseline, eyes open, about one minute |
| S001R02, S002R02 | Baseline, eyes closed, same participants |
| S001R03 | Task 1, real left or right fist. T0 rest, T1 left fist, T2 right fist |
| S001R04 | Task 2, imagined left or right fist. T0 rest, T1 imagine left, T2 imagine right |

T1 and T2 mean something else in other run numbers. The movement lesson only uses R03 and R04, and it states the legend.

Recordings are 64 channels at 160 Hz. The site keeps O1, O2, C3, Cz, C4, Fp1, and Fp2.

## ECG

Lugovaya, T.S. Biometric human identification based on electrocardiogram. Master's thesis, Faculty of Computing Technologies and Informatics, Electrotechnical University "LETI", Saint Petersburg, June 2005.

ECG-ID Database (version 1.0.0). PhysioNet. https://physionet.org/content/ecgiddb/1.0.0/

Records used: Person_01/rec_1, Person_02/rec_1, Person_05/rec_1. Each is 20 seconds of lead I at 500 Hz. The lesson shows signal 1, the filtered lead stored in the file. Age and sex from the headers are not copied into the app.

The beat annotations are described by PhysioNet as unaudited R-peak and T-wave marks from an automatic detector.

## PhysioNet

Pollard, T., Moody, B.E., Lehman, L., Gow, B., Fernandes, C., Xie, C., Johnson, A., Mark, R.G., and Heldt, T. PhysioNet as a global platform for biomedical research. Nature Health, 2026. https://doi.org/10.1038/s44360-026-00096-z

The original platform paper is still worth naming: Goldberger et al., PhysioBank, PhysioToolkit, and PhysioNet, Circulation 101(23):e215–e220, 2000.


## Earth Lab

Mousavi, S. M., Sheng, Y., Zhu, W., and Beroza, G. C. (2019). STEAD dataset. IEEE Access. https://doi.org/10.1109/ACCESS.2019.2947848

Dataset: https://github.com/smousavi05/STEAD (CC BY 4.0). Two traces from the authors' EQTransformer sample bundle, pinned at commit a589da6504b11df8341fe1dc859a025f49955409, ModelsAndSampleData/100samples.hdf5 and 100samples.csv. Identifiers: 109C.TA_20060723155859_EV and 109C.TA_20061103155652_EV. CSV and HDF5 manual pick indices agree. The bundle retains all three components, rounds amplitudes to four decimals, and performs no additional filtering or calibration. License text: public/licenses/STEAD-CC-BY-4.0.txt.

Earthquake-wave explanation: USGS, https://www.usgs.gov/programs/earthquake-hazards/science-earthquakes
